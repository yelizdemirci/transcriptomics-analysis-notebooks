# Transcriptomics Analysis Notebooks

Example Python notebooks for single-cell and spatial transcriptomics analyses.

## Notebooks

- `cell2location_abundance_heatmaps.ipynb`  
  Cell2location abundance heatmaps across tissue regions and experimental conditions.

- `single_cell_celltype_subtype_sankey.ipynb`  
  Sankey visualisation of study, cell-type/RFP-status, and microglia/macrophage subtype relationships.

The Sankey plot is also provided as a static PNG and an interactive HTML file.
